## 提出先

回ごとのフォルダの中に、自分の学生番号4桁のフォルダを作成します。

第4回・学生番号4017の例：

```text
session04/4017/report.pdf
session04/4017/notebook.md
```

## GitHubでの提出方法

1. 自分の学生番号のブランチを作成します。第5回以降も同じブランチを使用します。
2. 指定されたフォルダに提出物を保存し、commit・pushします。
3. GitHubでファイルの内容を確認します。
4. Slackのゼミナールチャンネルに、自分のブランチ内の提出フォルダのURLを投稿します。2人目以降は、最初の提出メッセージのスレッドへ返信します。

提出完了はSlackへのURL投稿で確認します。Pull Requestの作成は不要です。提出物は各学生のブランチに保存されます。GitHub上のブランチ選択で学生番号に切り替えて確認できます。

自分の学生番号フォルダだけを変更し、mainにはpushしないでください。仮想環境（zemi_04など）は提出せず、各回で指定されたファイルを追加してください。
