1．Docker+GPU  
　はじめに、ホスト側のGPUが認識できているか確認するために"nvidia-smi"を実行し、GPU情報が表示された。GPUの確認ができたら、Dockerが利用できるかどうかを"docker --version"で確認した。Dockerのバージョンが表示されたため、利用可能と判断した。次に、コンテナ内でGPUが認識できているか"sudo docker run --rm -gpus all nvidia/cuda:12.9.1-base-ubuntu24.04 nvidia-smi"で確認するとエラーが発生した。エラーを修正してGPUが使えるようになったら、作業用フォルダにmain.pyとDockerfileのプログラムを作成して、保存した。Dockerイメージの作成では"sudo docker build -t mygpu ."を実行すると、ビルドする時間が長かったが作成することができ、"sudo docker images"で確認した。GPU付きでDockerを実行すると正常に動作し、行列計算のテストに移った。main.pyの内容を書き換えたためコンテナには反映されないので、再ビルドを行い、"sudo docker run --gpus all mygpu"で実行すると、GPU上で計算がされていた。最後に、WindowsのGPU使用状況を"nvidia-smi"で確認し、DockerコンテナがGPU利用している様子を確認した。

問題点：コンテナ内でGPUが認識できているかの確認では、コマンドを実行するとエラーが発生した。→手順よりエラーの対処を行うために、各設定・再起動をした。完了後、再度コマンドを実行すると、コンテナ内でGPUが使えていた。
