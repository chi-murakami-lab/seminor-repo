1．Docker  
　Ubuntuターミナルでパッケージを更新し、Dockerを更新した。インストールが成功しているかバージョンの確認をして、その後Dockerサービスの確認を行った。Dockerのテストを"sudo docker run hello-world"で実行すると、"Hello from Docker!"が表示された。これにより正常に動作していた。Dockerイメージの確認として"sudo docker images"でPC内に保存されているイメージ（設計図）一覧を表示した。今回はhello-worldというイメージから、hello-worldコンテナを作成して実行していた。"sudo docker ps -a"により作成・実行されたDockerコンテナの一覧を表示し、不要なコンテナ・イメージの削除をして整理した。そのとき、"sudo docker rm <CONTAINER_ID>"および"sudo docker rmi hello-world"でコンテナ・イメージの削除を行った。

2．Docker+Python  
　作業用フォルダを用意し、VSCodeからmain.pyを作成した。main.pyの内容は"print("Hello Docker")"であり、"cat main.py"で内容を確認できた。その後、どのような環境で行うのか定義する設定ファイルとしてDockerファイルを作成した。"nano Dockerfile"で拡張子がないファイルを作成できた。内容は同様に"cat Dockerfile"で確認できた。Dockerイメージの作成、Dockerコンテナの実行と確認をして、main.pyの内容を"print("Hello Docker")　print("Version 2")"に書き換えた。しかし、イメージを更新していないため、
変更前の内容が"sudo docker run mypython"で表示された。イメージの再ビルドを"sudo docker build -t mypython ."で行い、Dockerコンテナの再実行をすると変更後の内容"Hello Docker"　"Version 2"がそれぞれ表示された。最後にDockerイメージの削除、ベースイメージの変更としてDockerfileの内容を書き換え再ビルドと再実行を行った。

3．Docker+GitHub  
　PCに使用するツールがインストールされているか"git --version"と"docker --version"で確認した。作業用フォルダを作成、GitHubからリポジトリの取得をした。取得する際は、記載されていたWebにアクセスしてクローン用のURLをコピーし、"git clone <リポジトリURL>"と"cd getting-started"で行った。また、Dockerイメージの作成、ビルドをしてDockerfileの内容を修正した。Dockerfileの修正は、"--platform=$BUILDPLATFORM"などの箇所を削除した。"sudo docker images"で確認し、"sudo run -dp 3000:80 getting-started"でDockerを実行した。ブラウザで"http://localhost:3000"にアクセスすると「Docker Getting Started」の画面が表示された。最後に、コンテナの削除をした。

問題点：不要なコンテナ・イメージの削除をするとき、CONTAINER_IDの指定を誤ってしまった。→表示されているCONTAINER_IDをすべて削除する必要があった。Dockerfileの書き換える場所を間違えた。→VSCodeのターミナルで書き換えた。GitHubのDockerfileの修正をしていなかったため、エラーが発生し正常に処理されなかった。
